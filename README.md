# 🌦️ Desktop Weather (Погода на рабочем столе) v1.0

Красивое, плавное и производительное приложение для Windows на **C# (.NET 9 / WPF)**, которое отображает живые атмосферные погодные эффекты, цветовую подсветку экрана и звуки прямо поверх вашего рабочего стола с удобным управлением через системный трей (возле часов).

---

## ✨ Возможности приложения:

### 1. 🌈 10 видов атмосферной погоды:
- ❄️ **Снег** — плавный снегопад с возможностью выбора стиля (резные кристаллы или мягкие хлопья).
- 🌧️ **Дождь** — реалистичные наклонные струи с брызгами от нижней границы экрана.
- ⚡ **Гроза** — плотные грозовые облака вверху экрана, вспышки молний и раскаты грома (без капель).
- 🌸 **Сакура** — нежные кружащиеся розовые лепестки сакуры.
- 🍁 **Листопад** — теплые золотые и багряные осенние листья с мягким покачиванием.
- ✨ **Светлячки** — волшебные мерцающие ночные огоньки с мягким свечением.
- 🌫️ **Туман** — таинственные полупрозрачные дымчатые волны тумана.
- 🔥 **Огонь** — живое пламя с искрами и языками огня снизу экрана.
- 💧 **Капли воды** — эффект капель, стекающих по стеклу монитора.
- 💨 **Ветер** — динамичные волнообразные струи и порывы свежего ветра.

### 2. 💾 Индивидуальные профили для каждой погоды:
- У каждого типа погоды **свои независимые параметры** (количество частиц, скорость, ветер, масштаб, прозрачность, стиль снега, тучи).
- Настройки автоматически сохраняются и восстанавливаются при переключении между погодами.

### 3. 🎨 Цветовая атмосфера экрана (Color Filter):
- Мягкая тонировка экрана под настроение погоды (холодный зимний, грозовой темный, ночной индиго, теплый янтарный и т.д.).
- Специальная двухслойная архитектура исключает мерцание приложений и игр (DWM-friendly).

### 4. 🎧 Атмосферный звук:
- Мягкий высококачественный эмбиент (дождь, гроза, потрескивание костра, шум ветра, ночные звуки) с плавной регулировкой громкости с шагом 1%.

### 5. ⚙️ Удобство использования:
- 🖱️ **Клик сквозь погоду (Click-through):** эффекты не мешают работать с иконками, папками и окнами.
- 🕒 **Системный трей:** сворачивание в область уведомлений, быстрое переключение погоды по правому клику.
- 🚀 **Автозапуск:** возможность запускать приложение вместе со стартом Windows.
- 📌 **Создание ярлыка:** создание ярлыка на рабочем столе в один клик прямо из настроек или трея.
- 🌐 **Два языка:** русский и английский с мгновенным переключением в один клик.

## 🚀 Установка и запуск:

### Быстрый запуск (Portable):
1. Скачайте файл **`DesktopWeather.exe`** (или архив **`DesktopWeather_v1.0.zip`**).
2. Запустите **`DesktopWeather.exe`**.
*(Приложение полностью монолитное: иконка, все 10 погодных эффектов и звуки зашиты внутрь одного файла. Не требует установки .NET или сторонних компонентов).*
